# Data-Science

## Project Title:
Exploratory Data Analysis on Heart Disease Risk Factors Using R

## Description:
Conducted an in-depth exploratory data analysis (EDA) on heart disease risk factors using R. Analyzed key variables such as BMI, Age, Income, and Smoking status from the BRFSS 2015 dataset. Applied statistical techniques to compute mean, median, mode, and skewness. Visualized distributions through histograms, boxplots, and bar plots. Incorporated normal distribution curves and comparative analysis of smoker vs. non-smoker groups. This project provided insights into the correlation between health indicators and heart disease risk, aiding in data-driven decision-making for public health research.
